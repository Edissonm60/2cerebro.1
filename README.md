# EM Suite PRO

Suite de gestión para seguridad electrónica, creación de contenido, estudio y oficina.

**Desarrollado por Ing. Edisson Macías Quevedo** · WhatsApp 310 886 4803

## Primera vez

1. Abre la página e instálala desde el navegador (botón **Instalar app**).
2. Ve a **🔔 Alertas → ⚙ Configuración** y pega la configuración que te entregaron
   (el texto que empieza con `EMCFG1.`).
3. Ve a **Sistema → Licencia** y activa tu clave.

Sin licencia el programa funciona en modo demostración: guarda en tu equipo,
pero no sincroniza entre equipos ni envía avisos.

---

Este repositorio contiene **solo la aplicación**. No incluye llaves, tokens ni el
generador de licencias.
